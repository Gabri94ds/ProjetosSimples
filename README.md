# Projetos Simples
Pequeno repositório para alocar projetos simples de estudo

## Objetivo
O objetivo desse repositório é ter projetos simples compartilhados e demonstrar as principais lições aprendidas durante a montagem e execução.

## Projeto n.1 - Atualização de estoques
O projeto de atualização de estoques consiste em criar um programa que faça uma atualização de estoque de produtos usando uma estrutura de dados do tipo array. A ideia é usar essa estrutura de dados e suas funcionalidades para aprender mais

### Estrutura
O projeto está estruturado em dois arquivos: produtos.py e main.py.
main.py: execução do programa
produtos.py: funções e controle

### Funcionalidades
- Consultar produtos
- Calcular o valor total do estoque
- Identificar produtos com estoque baixo

### Melhorias futuras
 -Integração com banco de dados
 - Interface gráfica

### Aprendizado obtido durante o projeto
- Estrutura de dados Array
- Arrays unidimensionais
- Indexação, busca linear, vetorização e máscaras booleanas
